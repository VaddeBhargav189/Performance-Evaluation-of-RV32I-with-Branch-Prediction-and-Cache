# Enhanced Processor

The **enhanced 5-stage pipelined RV32I processor** was developed by extending the original processor with a **cache and branch prediction** to improve overall processor performance.

The complete enhanced processor is maintained in a separate repository, which includes the **RTL source files, testbench, simulation results, implementation files, and project documentation**.

The enhanced processor used in this performance analysis is based on that implementation.
