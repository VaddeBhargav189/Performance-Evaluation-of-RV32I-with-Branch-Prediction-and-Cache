# Baseline Processor

The complete **5-stage pipelined RV32I processor** was designed and implemented as a separate project and is maintained in a dedicated repository named **RISC-V  RV32I Processor**.

The repository includes the complete **RTL source files, testbench, simulation results, implementation files, and project documentation**.

The baseline processor used in this performance analysis is based on that implementation.

**Original Processor Repository:**
